# Hidden Leaf Village

A 3D first-person agent world for Aryan Nehru's AI agents — a Naruto-homage hidden
ninja village with a Hokage Rock carved with his top agents' faces. Drag to look,
WASD to walk, Shift to run. Click captures the mouse, Esc releases it. On phone:
left joystick plus right-side drag-to-look.

This is a static snapshot build: agent statuses are baked in at build time.
Rebuild from the source project (`tools/build-preview.mjs`) and push to update.
